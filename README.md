# Ink-House — Replica paintings

Лендинг магазина репродукций картин «Ink. House». Статичный сайт без бэкенда: каталог работ с фильтром по стране художника, баннер с новой коллекцией, блок о команде и контакты.

## Возможности

- главный экран с описанием магазина
- каталог репродукций: автор, название, техника и размер, цена
- фильтр по странам: Франция, Германия, Англия
- баннер с новой коллекцией
- блок «Наша команда»
- подвал с контактами и навигацией
- адаптивное меню-бургер для мобильных устройств
- favicon и `site.webmanifest` для иконок на разных устройствах

## Технологии

- HTML5
- CSS3
- JavaScript (без библиотек и фреймворков)

## Запуск

Сборка и сервер не нужны. Склонируйте репозиторий и откройте `index.html` в браузере:

```bash
git clone https://github.com/Fulle-stack/Replica-paintings.git
cd Replica-paintings
```

## Структура проекта

| Файл / папка | Назначение |
|--------------|------------|
| `index.html` | разметка страницы |
| `style.css` | стили |
| `burger.js` | открытие и закрытие мобильного меню |
| `filter.js` | переключение каталога по странам |
| `img-poster/` | изображения: картины, иконки, логотип, фон |
| `favicon-*.png`, `favicon.ico`, `apple-touch-icon.png`, `android-chrome-*.png` | иконки сайта |
| `site.webmanifest` | манифест сайта |
